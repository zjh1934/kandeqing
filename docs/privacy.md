# 看得清 · 隐私说明

**一句话：这个 App 根本没有申请 `INTERNET` 权限，Android 从系统层面就不给它联网的能力。**

不是「我们承诺不上传」，是没有这个能力。这一条可以直接在
[`app/src/main/AndroidManifest.xml`](../app/src/main/AndroidManifest.xml) 里核对，不需要信任任何人。

---

## 读到的字去哪了

1. 你点屏幕上的字时，App 通过 Android 官方无障碍接口读取当前屏幕的文字节点
2. 文字只存在内存里，用来拼成要朗读的那一段
3. 交给系统 TTS 引擎念出来
4. 念完即释放

**不写文件、不进数据库、不进剪贴板、不进日志、不发网络请求。**

## 日志记什么

只记软件自己的运行状态，例如「按下了」「开始朗读了」「抓到多少段」「引擎初始化失败」。
**任何读到的文字内容都不写进日志。**

## 没有的东西

- ❌ 联网权限（`INTERNET`）
- ❌ 第三方 SDK / 统计 / 埋点 / 崩溃上报
- ❌ 广告
- ❌ 账号、登录、注册
- ❌ 云端 TTS（用的是手机本地已安装的语音引擎）
- ❌ 截图 / OCR / 屏幕录制

## 申请了什么

| 权限 | 为什么必须 | 能不能关 |
|---|---|---|
| 无障碍服务 | 画悬浮球、读屏幕文字、控制放大 —— 这是 Android 唯一途径 | 关了就没法用 |
| 震动 | 点中 / 开始读 / 读不到时给一下触感 | 能，在「悬浮球」页关 |
| 前台服务 + 通知 | 让系统别随手杀掉服务 | 通知可划掉 |
| 显示在其他应用上层 | 极少数机型无障碍浮层加不上时的兜底 | 正常机型用不到 |

**没有「存储」「位置」「通讯录」「相机」「麦克风」中的任何一项。**

## 不特判密码框

代码里没有任何密码框识别或跳过逻辑，点哪读哪。原因是这个 App 不联网、数据不出本地、
日志也不记录读到的内容，密码不会因此泄露；反过来，很多正常输入框会被系统误标成密码，
特判反而让验证码、金额、普通输入框读不出来，还会在每个节点上多一次跨进程 `isPassword()` 调用。

## 可审计

源码全开，MIT 协议。想验证「不联网」，除了看 Manifest，也可以：

- 在手机的「应用权限」里看，根本没有「网络」这一项
- 用任意流量监控工具观察，这个 App 不会产生任何连接
- 直接搜源码里的 `http` / `Socket` / `OkHttp` 等字样

有疑问或发现问题，欢迎提 [Issue](https://github.com/zjh1934/kandeqing/issues/new/choose) 或看 [安全与反馈](../SECURITY.md)。
